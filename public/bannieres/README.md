# Photographies de bannière

Déposez ici vos photos pour remplacer les illustrations par défaut.

| Fichier attendu       | Page concernée     |
| --------------------- | ------------------ |
| `accueil.jpg`         | Accueil            |
| `services.jpg`        | Nos services       |
| `realisations.jpg`    | Réalisations       |
| `comment-ca-marche.jpg` | Comment ça marche |
| `actualites.jpg`      | Actualités         |
| `contact.jpg`         | Contact            |

Extensions reconnues : `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.

Format conseillé : environ 2000 × 1000 px, moins de 400 ko. Une partie du
public consulte le site depuis un smartphone sur une connexion lente payée au
volume — compressez vos images (par exemple avec squoosh.app).

Un voile dégradé est appliqué automatiquement : le texte blanc reste lisible
même sur une photo claire. Privilégiez malgré tout des images dont la moitié
gauche n'est pas trop chargée, c'est là que se place le texte.

Tant qu'aucun fichier n'est présent, le site affiche ses illustrations SVG :
il n'y a jamais de bannière vide ou cassée.
